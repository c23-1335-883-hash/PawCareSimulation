# PawCare

PawCare is a 2D pet-care simulation game for Android, made with Unity as a BSIT capstone project.
The player adopts a puppy or kitten, looks after its needs, and helps it grow from Baby to Young to Adult.

## Game purpose

PawCare lets players practise responsible pet care in a simple, friendly way: feeding, giving water,
bathing, grooming, playing, cleaning up, and visiting the vet. Each finished care action shows a short
pet-care lesson, and good care is what makes the pet grow.

## Main gameplay features

- **Pet selection** – 20 breeds (10 dogs, 10 cats), with a naming popup.
- **Pet needs** – Food, Water, Clean, Energy and Mood. They drop slowly over time, including (more gently) while the game is closed.
- **Care interactions** – Feed, Water, Clean/Bath, Groom and Play (ball fetch), plus rest and cuddle.
- **Room messes** – messes appear over time and can be cleaned up.
- **Vet clinic** – check-ups, illnesses, treatment, after-care and vaccines.
- **Mini-games** – Catch the Treats, Paw Match, Pop the Fleas, Avoid the Obstacles.
- **Coins and shop** – treats, accessories and room themes; Bond level, pet personality and a 7-day daily reward.
- **Save and continue** – progress is saved on the device; Continue, New Pet and Reset Save are available from the main menu.
- **Settings** – music volume, sound volume and Reduce Motion, plus a Pet Care Guide.

## Pet growth / evolution

Growth is driven by **Care Points**, which never reset when the pet evolves.

| Care Points | Stage |
|---|---|
| 0 – 199 | Baby |
| 200 – 499 | Young |
| 500 and above | Adult |

Care Points are earned only for care that was finished and needed:

| Action | Care Points |
|---|---|
| Feed | +10 |
| Bath | +10 |
| Play (fetch, or a scored mini-game round) | +10 |
| Clean a room mess | +5 |
| Vet check-up | +15 |

| Item | Details |

| Engine | Unity **6000.3.25f1** (Unity 6.3 LTS) |
| Language | C# |

## Platform

- **Target:** Android phones and tablets, landscape
- **Minimum:** Android 7.1 (API 25), ARM64
- **Scripting backend:** IL2CPP

## How to open the project

1. Install **Unity 6000.3.25f1** through Unity Hub, with the **Android Build Support** module.
2. Clone this repository.
3. In Unity Hub choose **Add project from disk** and select the cloned folder.
4. Open the project. The first open takes a while because Unity rebuilds the `Library` folder.
5. Open `Assets/Scenes/start.unity` and press Play.

To build: **File → Build Profiles → Android → Build**. The scenes in the build are `start`, `selection`, `home` and `minigames`.

## Project structure

```
Assets/
  Animations/        Pet and UI animations
  Audio/             Music and sound effects
  Data/              ScriptableObject data (pet breeds and growth stages)
  Resources/         Prefabs loaded at runtime (loading screen, sound manager, feel config)
  Scenes/            start, selection, home, minigames
  Scripts/
    Gameplay/        Pet, CareInteractions and Vet logic
    MiniGames/       The four mini-games and their shared hub
    Models/          Data definitions
    Services/        Save system, Care Points, wallet, scene loading, audio
    UI/              Menus, HUD, shop, popups
  Settings/          URP render settings
  Sprites/           Pets, backgrounds, UI, mini-game and app icon art
  TextMesh Pro/      TextMesh Pro resources
Packages/            Unity package manifest
ProjectSettings/     Unity project settings
```

`Library/`, `Temp/`, `Logs/`, `UserSettings/` and build output are generated by Unity and are not stored in the repository. Only the game project is kept here; capstone documents are not.
